  and one subprocess fixture; none is counted as a runtime pass.
- Host Clippy, all-feature Linux, Windows MSVC and Apple Silicon macOS cross-target Clippy,
  formatting and `git diff --check` passed. Cross-target checks compile code and do not
  execute authenticated sessions on those platforms.
- Existing deterministic Reopen tests passed before extraction and after moving with their
  implementation. A new test checks successful source/provenance binding and rollback after
  either new-session creation or provenance writing fails. Existing race, late refusal,
  cleanup and marker-retention tests remain in place.
- Turn tests now publish through `Report`, including interrupted completion, delivery
  settlement and successor-claim protection. Context fixtures retain strict event decoding,
  exact event names, incomplete receipt refusal and provenance checks. Agy's transcript test
  checks incomplete full-result deferral before pending-turn lookup, read-only diagnostic
  evidence and subsequent incremental publication.
- The first full run found two stale policy fixtures: the expected public version and two
  runtime literals whose defining files moved into Reopen. Only their version/location
  expectations changed; literal counts and values were preserved. The policy suite and
  final full suite then passed.

An independent source review compared all four changes with `a3a2797`, including moved tests,
and found no concrete defect or policy drift. Reopen gate timing and lock order, query output
and read policies, and Agy result-before-failure ordering were unchanged. The review did not
run live providers. Codex, Claude and Pi adapters and terminal adapters are unchanged.

## Authenticated round trips

Each provider ran the candidate's public `self-test` in the repository workspace,
sequentially with `--terminal windows-console --timeout-secs 120 --json`. The ordinary
state root and provider defaults were used, without `--isolated`, model overrides or
`--yolo`. No new workspace trust or tool approval was answered by this task.

The five steps are ask, initial result, tell, follow-up result and cleanup. Agy's ask passed,
but no initial result arrived within 120 seconds. Its own log reported the pending turn
waiting for `RunCommand` approval; the diagnostic identifies the last observed confirmation,
not proof that a dialog is still open. No follow-up or retry ran. This is not an Agy
round-trip pass or proof of a new result-reader defect.

A separate read-only inspect confirmed every owned session closed, with no live owner and
no turn claim. Records were retained; unrelated sessions were not changed. The matrix uses
the `windows-console` backend; physical tab disappearance and focus were not observed.

## Limits

Authenticated macOS runtime, other terminal applications, Warp, approval submission,
absent Codex shared-daemon behavior, screen-lock behavior, cold startup and UI/physical-focus
assertions were not verified. Linux managed sessions remain unsupported. Reopen races and
damaged-record transitions were deterministic tests, not induced in real provider sessions.

This record identifies a local source build. Main CI artifacts, annotated tag validation,
immutable publication, downloaded release bytes and attestations are separate release checks.
The installed executable was not replaced. Earlier macOS live results are historical evidence,
not a live pass for this version.
