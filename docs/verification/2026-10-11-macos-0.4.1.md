# Terminal Agent Bridge 0.4.1: macOS verification

## Candidate and environment

Production source: main `c93cb633f2e8bdb2ddd80a48c344f9014a1f6e67`, the merge of pull request
#112 (child process environment, #108). The release branch adds the version, the release notes
and this record only. Rust 1.98.1 on Apple Silicon macOS 26.6.2; WezTerm 20240203-110809-5046fc22,
codex-cli 0.162.1, Claude Code 2.1.296, Pi 1.0.4, Agy 1.3.3. The screen was unlocked for every
live check below.

The checks ran from a Claude Code Bash tool, so the calling environment held the twelve Claude
variables the release removes (`AI_AGENT`, `CLAUDE_CODE_BRIDGE_SESSION_ID`,
`CLAUDE_CODE_CHILD_SESSION`, `CLAUDE_CODE_ENTRYPOINT`, `CLAUDE_CODE_EXECPATH`,
`CLAUDE_CODE_MESSAGING_SOCKET`, `CLAUDE_CODE_MESSAGING_TOKEN`, `CLAUDE_CODE_SESSION_ATTENDED`,
`CLAUDE_CODE_SESSION_ID`, `CLAUDE_EFFORT`, `CLAUDE_PID`, `CLAUDECODE`).

## Automated checks

- Full serial suite on the release branch: 866 passed / 0 failed / 6 ignored. The ignored tests are the live fixtures
  and one subprocess fixture; none is counted as a runtime pass.
- Host clippy, Linux and Windows cross-target clippy, formatting and `git diff --check` passed
  on the release branch.
- Pull request #112 passed all six CI jobs before merging. Each of its two rounds was implemented
  by one Codex `gpt-6-astra` session and reviewed by an independent `gpt-6-astra` session (first
  round mergeable after fixes, fixed in the implementing session; second round mergeable as is);
  the plan was critiqued once at `xhigh` effort before implementation.
- A doctor integration test that clears the caller's markers passed in the Codex sessions but
  failed in the Claude Code Bash tool after the two new markers were added, because only the
  Bash tool's environment holds them; the test now clears them too.
