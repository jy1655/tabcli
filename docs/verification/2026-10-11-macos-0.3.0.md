## Scope

This record covers the release branch's automated checks, the rehearsal, and the macOS live
checks listed above. Native Windows and Linux runtimes, Warp, other provider/terminal combinations,
screen-lock behavior, physical focus, onboarding or approval dialogs, missing-daemon
behavior and injected failure recovery are not verified here. Cancelling an in-progress
turn (#72) is not part of this release.
