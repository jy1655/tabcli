## Authenticated round trips

Not yet run when this record was first committed: the screen of the verifying Mac was
locked, and a locked screen is a known cause of launch failures on macOS. The live run
(each provider's `self-test` with the candidate executable, then `status`, a `hold`
cycle with a refused and a released follow-up, `wait` over two addresses, and `doctor
--probe`) is added to this record before the tag is pushed, or the tag is pushed with
this section stating that no live round trip was run for 0.3.0.

## Scope

This record covers the release branch's automated checks and the macOS live checks listed
above. Native Windows and Linux runtimes, Warp, other provider/terminal combinations,
screen-lock behavior, physical focus, onboarding or approval dialogs, missing-daemon
behavior and injected failure recovery are not verified here. Cancelling an in-progress
turn (#72) is not part of this release.
