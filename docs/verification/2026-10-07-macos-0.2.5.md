  and one subprocess fixture; none is counted as a runtime pass.
- A subsequent test verifies that convergence preserves status, claim and journal when
  recovery is damaged but the owner is live or absent. The four `converge_` tests passed
  after this addition. Final CI therefore includes 753 passing macOS tests.
- Host Clippy, all-feature Linux and Windows MSVC cross-target Clippy, formatting and
  `git diff --check` passed. Windows GNU Clippy also passed. Cross-target checks compile
  code and do not execute authenticated sessions on those platforms.
- Before the fix, `converge_repairs_dead_owner_even_when_completion_recovery_is_damaged`
  failed because no closed tombstone existed. Afterward, repair closes the dead-owner
  session with the recovery damage retained and no result published. The existing
  successful completion-before-repair fixture remains byte-identical.
- Agy tests exercise rejected trust/correlation/readiness preparation, one paste with
  the ready read's offset, not-sent/uncertain sends and missing receipts. Existing
  recorded-log gate and receipt tests still run. Codex tests exercise queue refusal,
  UUID targeting and uncertain delivery. Claude tests exercise descendant containment,
  pre-start expiry and Windows suspended startup. Status tests check unchanged bytes
  after an invalid transition or generation overflow. Journal comparison tests require
  exact bytes inside the read limit, including noncanonical JSON and invalid UTF-8.

## Limits

approval prompts, absent Codex shared-daemon behavior, screen-lock behavior, cold startup,
and UI/physical-focus assertions were not verified. The damaged-record and helper-timeout
paths were deterministic tests, not failures induced in real provider sessions.
