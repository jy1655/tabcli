# Terminal Agent Bridge 0.4.47

On native Windows, Claude, Agy and Pi can launch in a running local Herdr Core
with `--terminal herdr`. Inside a verified Herdr terminal, Bridge selects Herdr
automatically for these providers. Windows Codex uses the managed console.
The [Windows guide](../terminals.md#herdr-core-on-native-windows) covers setup
and attaching with PowerShell. The [Windows PR](https://github.com/jy1655/tabcli/pull/398)
records a live Pi launch, follow-up, screen read and close on Windows 11 at
`505f0e7`. Windows Herdr has no authenticated run for Claude or Agy. Agy
withholds input until its startup log confirms readiness.

On macOS and Linux, a session launched from a verified Herdr terminal appears
under the caller's tab. Bridge asks the core to let the child outlive the
caller and to disable child notifications. The macOS run confirmed the listing
and core settings. Linux parenting is covered by scripted-core tests. From outside Herdr, an explicit launch creates
a parentless terminal.

If a Herdr terminal finishes outside Bridge on macOS or Linux,
`tabcli close-session <session> --explicit` can now remove the finished, unkept
terminal after checking its identity. A macOS live run confirmed removal and
repeat close. Regression tests cover handles in the 0.4.45 and 0.4.46 format. The [terminal guide](../terminals.md#herdr-core-on-macos-and-linux)
explains how to park a temporary pane or recover a finished terminal with keep
enabled.

The [release verification procedure](../releasing.md) now checks the Windows
notice files with their expected CRLF line endings and shows how to verify the
four integration packages from a full release download.
