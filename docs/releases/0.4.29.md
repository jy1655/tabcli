# Terminal Agent Bridge 0.4.29

0.4.29 makes Request wait tests deterministic and centralizes the iTerm2 session lookup
traversal introduced in 0.4.28. Public timeout and terminal behavior are preserved.

## Request wait coverage

Read-only polling in `wait` and `result --wait` now uses the existing private Clock seam.
Tests advance simulated time to prove that normal-to-busy and damaged or deleted Receipt cases
actually execute another observation pass.

The timeout still allows an in-progress observation pass to finish and returns a Result
found in that pass, even after the deadline. Internal zero-timeout calls still observe one
pass; the CLI continues to reject a zero timeout. The new deadline test reads an already
published Result after advancing time; it does not simulate a provider publishing after
the deadline.

## iTerm2 lookup maintenance

The five session lookup scripts now share one adapter-private compile-time traversal.
It obtains the evaluated window-ID specifiers before walking tabs and sessions. Each
operation retains its own not-running, missing-session and matching policy: ownership
verification requires exactly one match and a nonempty TTY, while the others return at
the first match. Screen lookup, case-sensitive comparison and guarded input remain in
one automation call.

The generated send, verify and close scripts are byte-identical to 0.4.28. Presence uses
a block-form conditional, and the screen script only renames traversal variables. The
script model now exercises all five operations, including guarded input, during window
reordering and checks missing, duplicate, not-running and missing-TTY cases. The former
ordinal traversal fails the same model. Presence also joins the application-dictionary
compile test.

## Verification and upgrade

These deterministic model and source checks do not constitute new live iTerm2 or provider
verification. Stable window references do not freeze tabs or the renderer, or grant input
authority. Provider adapters, consent and permission policy are unchanged.

The existing [open-session upgrade notes](0.4.25.md#upgrade-notes) still apply. Do not
downgrade binaries used by open sessions. The release includes macOS and Windows CLI
archives and the Claude, Codex, Agy and Pi integration packages, with checksums.
Integrations contain instructions and no engine binary.
