# Terminal Agent Bridge 0.4.44

0.4.44 reorganizes project instructions and terminal internals (#391, #392).
Commands, provider behavior and stored session formats are unchanged.

## Changes

- **Project instructions:** the root `AGENTS.md` now contains shared rules and explicit
  routing to ten provider and platform boundary files. Claude keeps the same entry through
  `CLAUDE.md`. A repository check enforces the 32 KiB root limit and validates the routes.
- **Linux close observation:** tmux's implementation owns observation of its recorded server
  birth. Close still requires the registered surface binding and preserves the distinction
  between process identity, unreaped zombies and actionable server exit.
- **Terminal records:** terminal kinds own their identity fields through a dedicated record
  module and constructors. Existing JSON names, defaults, omitted fields and aliases remain
  compatible, including historical incomplete and mixed-kind records.

## Verification and upgrade

- The implementation passed 1,586 local Rust tests (one manual test ignored), the Python
  scripts suite, Clippy, fmt, language and instruction checks. Cross-target Clippy also passed
  for macOS and Windows; the pull request's native Linux, macOS and Windows CI jobs passed.
- Claude Opus independently reviewed the instruction split, close observation and record
  compatibility. The review's important findings were resolved and checked again.
- Authenticated provider runtime tests were not part of the implementation checks. Those
  results are separate from automated CI and any installation smoke test.
- No record migration or new provider permission is required. Existing downgrade restrictions
  for provider completion protocols and Linux sessions still apply.
