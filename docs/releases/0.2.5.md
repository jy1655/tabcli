# Terminal Agent Bridge 0.2.5

0.2.5 fixes dead-owner repair being skipped when completion recovery fails, and completes
bounded improvements from the remaining architecture review. It preserves provider-owned
transport, correlation, workspace trust, and terminal close authority.

## Changes

- Session convergence delegates recovery and dead-owner repair to one operation. Previously,
  its redundant first recovery returned early on damage, preventing the existing repair from
  settling the dead owner's session. Repair now retains that damage in the close diagnostic;
  it does not publish an unverified result or resend input.
- Codex explicitly declares its native queue transport. The unreachable terminal-paste
  fallback branch and failure flag are removed. Queue rejection remains not-sent and an
  uncertain queue submission remains claimed. Transport diagnostics now name this path
  `provider-native-queue` instead of advertising a fallback that the adapter refused.
- Agy prepares a paste only after the required trust and readiness checks, then consumes the
  prepared turn once. Its receipt uses the offset from the ready read. Windows follow-ups
  retain their existing rule: startup was gated by the initial paste. No new trust approval,
  readiness window, or retry is introduced.
- The session state module owns status writes, generations, tombstone preservation, and
  diagnostic-only residual-surface amendments. Refused transitions and generation overflow
  leave the previous record unchanged. The serialized record format is unchanged.
- Claude messenger uses the existing provider process containment implementation, including
  Windows suspended startup and Unix process groups. Claude still owns its messenger protocol,
  deadline, retry decision, payload guard, and delivery classification.
- Timeline and publication readers use one journal-to-event byte comparison. Timeline keeps
  its read-once, strict UTF-8 behavior and never repairs records.

## Verification and remaining scope

See the [verification record](../verification/2026-10-07-macos-0.2.5.md) and the
[review disposition](../verification/2026-10-07-architecture-follow-up.md).

This release does not complete all twelve original architecture proposals. Broad adapter,
fixture, and provider-record redesigns remain deferred. Warp missing-binding recovery (#87),
first-launch timeout diagnosis (#80), and the explicit Codex daemon option (#89) remain open.
