# TAB 0.4.48

TAB is the product name. The repository, Cargo package and executable are named
`tabcli`. Use your existing `tabcli` commands after upgrading.

Session listings, result timing, errors, doctor diagnostics and provider notices now
use TAB. For example, an empty `tabcli sessions` prints `no native TAB sessions`.
The assistant plugins also use TAB in their descriptions and status updates.

Existing plugin installation IDs, session records, environment variables, JSON keys
and provider protocol markers retain their original spelling. Scripts can continue
to read fields such as `bridge_observed_elapsed_ms`, and existing sessions remain
addressable by their original IDs.

On macOS the serial Rust suite passed 2,030 tests with six ignored. A local check
compared the old and new executables on an empty session list and a recorded result,
including its human-readable elapsed time and JSON value.
