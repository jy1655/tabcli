# Agent Bridge 0.1.1

0.1.1 fixes Codex follow-up delivery when no shared app-server daemon is running.
Bridge previously rejected `tell` before invoking `codex queue`, even though
Codex can enqueue through its own embedded server.

## Codex follow-ups

- Remove the shared-daemon prerequisite. The official `codex queue` command
  selects a shared or embedded server and its actual response determines
  acceptance.
- Keep the Codex 0.149+ requirement, established thread UUID, exact queue
  confirmation, bounded helper process, pending claim, and correlated `notify`
  completion. Queue acceptance alone is not a completed result.
- Keep terminal follow-up disabled and never retry an uncertain delivery.
  Bridge does not start, stop, or restart the user's shared daemon.
- Describe `doctor --probe`'s daemon check as an optional observation rather
  than a delivery prerequisite. Update the installation and runtime guidance.

Codex 0.157.0 enabled daemon auto-start for eligible interactive sessions, but
Bridge's `notify` configuration override still excludes its TUI from that path
in Codex 0.160.0. Keeping the completion hook and using Codex's official queue
backend selection avoids depending on auto-start eligibility.

Other provider adapters and the shared session lifecycle are unchanged.

## Verification and remaining limits

- The regression reproduces the previous rejection with a provider that refuses
  a daemon probe but accepts the addressed queue command. The updated adapter
  skips the probe, retains the pending claim, and publishes no premature result.
- Native Windows tests passed: 540 tests, no failures, 5 ignored. Clippy,
  formatting, and diff checks passed. Ignored tests are not runtime evidence.
- The installed Codex CLI 0.160.0 was also tested in an isolated home against a
  local mock model. Without a shared daemon, a separate queue client delivered
  to the selected thread, that thread completed and emitted its actual notify,
  and a second thread received no queued turn.
- This protocol probe is not an authenticated TUI round trip, a new macOS runtime
  test, or an agent-picker/terminal-cleanup check. It does not close #57 or #65.
- Codex's durable queue can take roughly 10 seconds to notice external input in
  the observed version. Closing a Bridge session does not cancel a queued item;
  a later resume of the same thread can consume it. Never resend an uncertain
  request automatically.

Source evidence, probe details, and validation results are in the
