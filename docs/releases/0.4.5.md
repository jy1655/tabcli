# Terminal Agent Bridge 0.4.5

0.4.5 moves three more pieces of knowledge to the modules that own them and changes no behaviour.
Each terminal adapter answers for its own close evidence, the Agy adapter is a module directory
instead of one file, and the turn claim's launch phases are named methods instead of flag flips
performed by the launcher, with the test-only entry points of the turn module gone. Records written
by 0.4.x are read as before.

## Changes

- Close evidence is declared per terminal adapter (`close_evidence.rs` beside each adapter). The
  Close authority decision no longer imports Terminal.app's helpers or takes its two Terminal.app-only
  parameters; it asks the adapter of the surface's kind whether the recorded Surface is proven absent,
  whether the application incarnation ended while the owner is live, what a resumable close may do,
  and which startup refusal it reports. Terminal.app holds the App incarnation logic and its owner
  teardown; iTerm2, Ghostty, Warp, WezTerm and the Windows console declare the presence-only answer
  explicitly. Every record read, observation order and refusal string is unchanged; the
  `requires_app_incarnation` fact is gone.
- The Agy adapter is the module directory `src/native/provider/agy/`: the adapter and its transports,
  workspace trust, terminal delivery, startup readiness, input receipt, the doctor checks and the
  transcript monitor each in their own file, with the tests beside each concern. Bodies, strings and
  the 54 tests are unchanged; the runtime-contract pins are the same 34 literals counted per file.
- The turn module's eighteen test-only entry points are gone; tests reach the turn lifecycle
  through the same seam as production (`claim`, `claim_ready`, `current_claim_token`, `Report`,
  `wait`), and the tests of partial transitions and orderings live beside the module. The Claim names
  its two launch facts, `fence_launch` and `startup_confirmed`, where the launcher flipped a retention
  flag by hand before; `rollback_on_drop` and `retain_in_place` are gone. Two deterministic tests pin
  the retention semantics at those points. `turn.rs` drops from 51 to 33 public functions.
