# Terminal Agent Bridge 0.4.46

Linux users can now launch a session in an already running local Herdr Core with
`--terminal herdr`, or use automatic selection from a verified Herdr terminal.
Linux keeps the bound bash handoff. macOS Herdr keeps its shell environment
capture and launch-stage diagnostics.

- If Herdr confirms creation but saving the binding and removing the terminal
  both fail, Bridge hands the confirmed surface identity back to the launcher.
  A later close can recheck the recorded handle and finish an interrupted removal.
- Terminal registration now selects the platform's launch-host handoff.
  The doctor probe follows that selection, and historical launch-host records
  retain their portable terminal names.
- Prompts are shorter across providers. Each adapter supplies its own correlation
  marker and framing. The request receipt retains the request source.
- Follow-ups to a Claude session started with a v0.4.45 completion hook keep
  the source prefix that hook expects. The Claude turn module writes both frame
  formats and reads pending records written before the upgrade.

The [Linux Herdr verification](../verification/2026-11-18-linux-herdr.md) covers
Claude, Codex and Pi round trips, and a follow-up from a newer sender to an older
Claude hook on tmux. Agy withheld input pending workspace trust in that check.
