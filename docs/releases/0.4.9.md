# Terminal Agent Bridge 0.4.9

0.4.9 ships one native Windows fix and the fourteen changes of the refactoring, anti-slop and
test-hardcoding review of 0.4.8 (#151 to #163). The visible change is on native Windows: a managed
session's PowerShell root and the provider forwarder are started from the plain executable path,
so PowerShell module auto-loading works again for everything that runs inside a managed session.
Records written by 0.4.x are read as before; no record schema, command or JSON field changed.

## Changes

- The managed PowerShell root and the provider forwarder start from the plain path (#166). Bridge
  resolves `pwsh.exe` to a canonical path, which on Windows carries the `\\?\` prefix, and passed it
  unchanged to `CreateProcessW` as the application name of the console root on both surfaces (the
  Windows Terminal tab host's request and the console window) and as the program of the
  PowerShell that runs the provider forwarder. PowerShell derives `$PSHOME` from that image path
  and prepended `\\?\c:\...\7\Modules` to `PSModulePath` for every descendant, which made module
  auto-loading fail (for example `Compress-Archive` from a `-File` script) while an explicit
  `Import-Module` worked. The launch site now converts the resolved path the way provider
  executables already were; identity and attestation keep reading the live image path.
- Tests organised by subject (#154). The 10,096-line `src/native/tests.rs` became `src/native/tests/`
  with one file per subject and a shared `support.rs`; the inline test modules of the Warp, Claude and
  WezTerm adapters moved to files of their own. 354 tests, names and bodies unchanged.
- The Claude adapter's registry cluster is an adapter-private module (#159): registry records,
  validation, directory resolution, holder observation and the resumed-holder wait live in
  `claude/registry.rs`; the messenger and its guard are unchanged.
- The timeline renderer is 88 lines instead of 438 (#158): per-concern rendering helpers over the
  captured records, a named entry value and one `unreadable_entry`; byte-identical output.
- Six unconditional `allow(dead_code)` suppressions are gone (#155): two clocks nobody read, two
  wrappers nobody called, and two live cancellation APIs that were described as future work.
- Two helpers are reused instead of copied (#156): the Claim-token grammar in the Codex, Pi and Agy
  adapters calls the shared predicate; Warp imports the shared shell quoting.
- Agy's deferred-reload window mode is deleted (#153). No rule set a window; the field, the gate
  state and the replay-only tests that kept it alive are removed, the trust-reload observation and
  its recorded fixtures stay.
- Tests derive values from their owners (#152, #151): the release version, the MSRV and the
  self-test cleanup budgets come from Cargo metadata and the source constants; the help fixture
  carries a version token; the Korean README's Install section is checked against the Cargo
  version like the English one.
- Deterministic test proofs (#160, #161, #162, #163): the Claude messenger's descendant-teardown test
  uses a FIFO handshake instead of a timed write; four tests reach their deadline branch by
  construction instead of racing a 10 to 100 ms budget; the query tests' read-only snapshots record
  directories as well as files; the record builders and the macOS launch fixture are shared; Node and
  PowerShell 7 are named as unit-test prerequisites and the Windows process tests resolve `pwsh.exe`.
- Comment sweep (#157): banners, the help header's em dash and the investigation chronology
  (session ids, timestamps, version history) left the source comments; constraints stay in one or
  two lines, and the moved facts are in dated "Source notes" sections of the verification records.
