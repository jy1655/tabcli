# Third-party notices

This file records the licences of every third-party package in Cargo.lock.
It is a superset of what any one binary links, including build-only,
development-only and other-platform packages. MIT is selected wherever offered;
additional mandatory licences are retained. Texts and copyright lines are copied
from the crate sources located by `cargo metadata --locked`, including shipped
COPYRIGHT, AUTHORS and NOTICE files.
Regenerate from the repository root with
`AGENT_BRIDGE_UPDATE_NOTICES=1 cargo test --test third_party_notices third_party_notices_match_lock -- --exact`.
The update mode is refused when CI is set and requires Cargo registry sources
(Cargo may download them); normal
tests read only repository files. Unknown licence expressions or missing licence
files require review and an explicit generator update.
